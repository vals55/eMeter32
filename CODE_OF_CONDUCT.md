# Code of Conduct

## Our pledge

We want this project to be a friendly, respectful and harassment-free place for everyone, regardless of age, experience, background, identity or opinions.

## Expected behaviour

- Be respectful and patient, especially with beginners.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and the community.
- Assume good intent and ask for clarification before assuming otherwise.

## Unacceptable behaviour

- Harassment, insults, personal attacks, trolling or discriminatory language.
- Publishing other people's private information without permission.
- Spam, advertising unrelated to the project, or other disruptive behaviour.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests that do not follow this Code of Conduct, and may temporarily or permanently block people for behaviour they consider inappropriate.

To report a problem, use the private reporting on the **Security** tab of the repository or contact the maintainer through the profile page. Reports are treated confidentially.

This Code of Conduct applies in all project spaces: issues, pull requests, discussions and any other place where the project is represented.
